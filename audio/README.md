# Backsound per tema

Letakkan file backsound (open source, CC0 atau CC-BY) di folder ini dengan nama:

| Tema | Nama file |
|---|---|
| Hutan Borneo | `hutan-borneo.mp3` |
| Luar Angkasa | `luar-angkasa.mp3` |
| Es Krim | `es-krim.mp3` |

Tema lain menyusul. Bila file belum ada, game tetap berjalan tanpa backsound.
Jangan lupa tulis kreditnya di bagian Tentang (About).
